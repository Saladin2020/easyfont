# Easy Font — studio usage guide

Original Thai / English / Malay pixel bitmap fonts for 2D games — **มะขาม 12** (dialogue) and **มะขาม 8** (UI) —
with correct Thai vowel and tone-mark stacking. Agents **check the game's text, draw missing glyphs and export**
BMFont `.fnt` + PNG, a Godot 4.3+ `FontFile` + `EasyFont` autoload, or a PixiJS v8 BitmapFont runtime. Nothing is
generated by AI and nothing calls a network. Fonts: SIL OFL 1.1; code: MIT.

Install is local only. Do not push or modify the upstream GitHub repo.

## Paths

| What | Path |
|---|---|
| Install (package 0.1.0, `<SHA>` on master) | `/workspace/indie-studio/tools/easyfont` |
| CLI wrapper | `node /workspace/indie-studio/tools/easyfont-cli.mjs` |
| Studio projects | `/workspace/indie-studio/projects/<Name>/` |
| Format | `/workspace/indie-studio/tools/easyfont/docs/FORMAT.md` |

A game's font sources live in `/workspace/indie-studio/projects/<Name>/fonts/*.easyfont`, exports in `exports/`.

## Commands

```bash
W=--workspace=/workspace/indie-studio/projects/<Name>
node …/easyfont-cli.mjs init $W
node …/easyfont-cli.mjs info $W
node …/easyfont-cli.mjs check $W [--text "every line" "the game shows"]        # exit 1 on missing / stacking issues
node …/easyfont-cli.mjs shape "น้ำ ปี่"                                         # presentation forms
node …/easyfont-cli.mjs render "สวัสดีจ้ะ" --dialogue "ป้านูรุล" --out shot.png $W
node …/easyfont-cli.mjs set-glyph € ".###/#.../###./#.../.###" --top 9 --font makham-12 $W
node …/easyfont-cli.mjs export --preset bmfont|godot|pixi|png|all $W
node …/easyfont-cli.mjs serve $W                       # http://127.0.0.1:8948
```

## Godot import

Export `--preset godot`, copy `easyfont/` into the game, add `res://easyfont/easyfont.gd` as the autoload
**`EasyFont`**. Use `EasyFont.apply(label, text, "makham-12")` (sets font, size, shaped text), keep Label autowrap off
and set `label.text = EasyFont.wrap(text, "makham-12", width)`. Easy UI: set `easyfont/makham-12.theme.tres` (or its
font) as the theme font. Run `godot --headless --path <export> --script res://test_font.gd` and expect `OK`.

## Pixi

`const ef = await loadEasyFonts(PIXI, "fonts/fonts.json"); stage.addChild(ef.text("น้ำชา", { font: "makham-12", fill: 0xf7ebd3, scale: 3, wrap: 300 }))`.

## Rules

Keep glyphs original; ship `OFL.txt` with the fonts. Thai names (people, settlements) are written in Thai script in
Thai text. Put U+200B between Thai words where lines may break.
